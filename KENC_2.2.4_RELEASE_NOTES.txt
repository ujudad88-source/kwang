KENC UI 2.0.2.2.4 - 객체 포함 3D 함체 유지 및 제작 전달 도면 동기화 수정

1. 실시간 WebGL 3D에서 객체별 변환/렌더링 오류를 격리했습니다.
2. WebGL 사용 불가 시 기존 SVG 3D 렌더러로 자동 복귀합니다.
3. 객체 렌더링 뒤 함체 외곽선을 다시 그려 객체가 본체를 가리는 현상을 방지했습니다.
4. 잘못된 크기/좌표 객체는 전체 장면을 중단하지 않고 해당 객체만 건너뜁니다.
5. KENC 제작 전달 도면 3D의 아크릴창 참조 오류(cxy 미정의)를 수정했습니다.
6. 제작 전달 도면 3D에도 객체별 오류 격리와 함체 윤곽 유지 처리를 적용했습니다.
7. Scene/Preview 갱신 이벤트와 제작 검토 센터 3D 미리보기를 직접 동기화했습니다.
