KENC UI 2.0 Build 003.6.1

기준 버전: Build 003.6

- 함·랙·자재·손도면 화면이 브라우저의 사용 가능한 전체 폭을 활용하도록 수정
- 전체 페이지 max-width 충돌 제거
- 표, 입력폼, 텍스트 카드, 작업 레이아웃을 화면 폭별 유동 그리드로 변경
- 사이드바 접기/펼치기 시 콘텐츠 폭 자동 확장
- 랙 화면: 선택/이미지 2열, 가격정보 전체 폭
- 자재 화면: 선택/계산, 이미지/단가, 참고정보의 반응형 균형 배치
- 손도면: 여유 폭은 중앙 2D 캔버스에 우선 배정
- 태블릿/모바일에서 모든 영역 1열 전환 및 가로 이탈 방지
- 기존 기능, 객체, Firebase, 가격 데이터 및 도면 엔진은 변경하지 않음
