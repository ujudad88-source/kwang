광전기통신 제품정보 V84 패치노트

1. 도면 자동 생성 파트 레이아웃 변경
- 기존 iframe 기반 입체도면 영역을 제거하고, 첫 번째 추천안 기반의 2D 도면 편집 레이아웃으로 교체했습니다.
- 상단 툴바 + 규격 입력 + 객체 목록 + 도면 화면 + 선택 객체 설정 구조로 재구성했습니다.

2. PC / 모바일 공통 대응
- 데스크톱에서는 3열 편집 구조로 표시됩니다.
- 모바일에서는 세로 1열 구조로 자동 재배치되어 같은 흐름으로 사용할 수 있습니다.
- 내부 다중 스크롤을 줄이고 페이지 기준 단일 스크롤 구조로 정리했습니다.

3. 2D 도면 편집 기능 추가
- 편집 면 탭: 정면 / 뒷면 / 내부 / 좌측 / 우측 / 상부
- 객체 목록: 환기구 / 타공 / 손잡이 / 명판 / 케이블 인입구 / 브라켓
- 객체 추가: 객체 선택 후 도면 클릭
- 객체 이동: 도면에서 직접 드래그
- 객체 수정: X / Y / 가로 / 세로 / 회전 값 입력 후 적용
- 객체 삭제 기능 추가

4. 보조 기능
- 현재 도면 상태 브라우저 저장 기능 추가
- 전체 초기화 기능 추가
- 현재 표시 도면 PNG 이미지 출력 기능 추가

5. 기타
- 문서 타이틀을 V84로 반영했습니다.
- 서비스워커 캐시명을 v84로 갱신했습니다.
