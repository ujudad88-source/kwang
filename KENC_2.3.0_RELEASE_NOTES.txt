KENC UI 2.0.2.3.0 - Unified 3D Scene Renderer

1. 실시간 WebGL 3D와 KENC 제작 전달 도면 SVG 3D가 동일한 Scene Graph 객체 목록을 사용합니다.
2. 선택 함체, 적층 함체, 객체 표시/숨김, 3D 제외, 출력 제외 조건을 공통 브리지에서 일괄 처리합니다.
3. 두 렌더러의 객체 개수와 렌더링 순서가 동일한 기준으로 계산됩니다.
4. 기존 UI, 객체 모델 세부 표현, 2D 기능 및 프로젝트 데이터 형식은 유지됩니다.
5. 공통 3D 진단 API KENC_UNIFIED_3D_BRIDGE.diagnostics(state)를 추가했습니다.

장점: 한쪽 3D만 객체가 누락되는 구조적 불일치를 줄이고 이후 객체 추가 시 수정 지점을 단일화합니다.
단점: WebGL과 SVG는 표현 방식이 달라 재질과 음영은 완전히 동일하지 않지만, 객체 선택·위치·크기·부착면은 같은 Scene 데이터를 사용합니다.
