KENC UI 2.0 Build 003

핵심 변경
- 손도면 생성기를 CAD형 Workspace 구조로 재배치
- 객체 팔레트 / 도면 캔버스 / 객체 속성 / 3D 미리보기 영역 분리
- 제작 중요사항과 적층 작업영역을 동일 디자인 시스템으로 통합
- 태블릿 2열, 모바일 작업 순서형 레이아웃 적용
- 입력창, 선택창, 버튼, 상태 표시의 포커스와 가독성 개선

보존 항목
- 접지, 투명아크릴창, 이중시건, 명판 및 명판명 등 기존 객체
- 객체 ID와 데이터 구조
- 좌표, 크기, 회전 계산
- 단독함체, 적층함체, 2D, 3D 미리보기
- 제작 중요사항, PNG/PDF, 공유 기능
- Firebase 로그인과 관리자 기능
