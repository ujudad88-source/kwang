광전기통신 영업지원 시스템 v0.0.4

- 모바일 첫 화면 파트 선택 카드 간격과 폭을 동일하게 최적화
- 손도면 생성 글자 세로 표시 및 비정상 줄바꿈 방지
- 모바일 하단 고정 메뉴 추가: 홈 · 랙 · 함 · 자재 · 손도면
- 버튼 눌림 애니메이션 및 지원 기기 햅틱 피드백 추가
- 화면 세로/가로 회전 시 레이아웃 자동 재배치
- 함 파트 제품과 규격표 사이에 단가 조정 기능 추가
- 빠른 조정 버튼: -20, -15, -10, -5, 기준, +5, +10, +15, +20%
- 직접 퍼센트 입력 및 현재 적용률 표시
- 기준단가 원본은 유지하고 화면 표시 단가만 조정
- 규격표 행 클릭/터치 시 Hover 스타일 선택 고정
- 다른 행 선택 시 기존 선택 행 자동 해제
- 선택 규격을 손도면 생성기의 가로·세로·깊이에 자동 입력
