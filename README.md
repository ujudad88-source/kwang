# 광전기통신 영업지원시스템

## 현재 버전
v0.0.6

## 배포
이 폴더의 전체 파일을 GitHub 저장소 루트에 업로드하면 GitHub Pages에서 정적 웹앱으로 사용할 수 있습니다.

## v0.0.6 변경사항
- 모바일 메인 카드를 `제목 + 한 줄 요약` 구조로 확정했습니다.
- iPhone Safari와 Android Chrome에서 설명이 한 글자씩 세로로 깨지는 현상을 방지했습니다.
- 모바일 카드 높이를 줄이고 카드 전체를 터치할 수 있도록 유지했습니다.
- 메인 카드의 큰 원형 장식을 제거하고 화살표를 간결하게 정리했습니다.
- 기존 v0.0.5의 로그인 액션, 화면 이력, iPhone 제스처 뒤로가기, Android 뒤로가기 기능을 유지했습니다.
- 변경 이력 파일을 `CHANGELOG.md` 대신 `README.md`로 통합했습니다.

## 관리 원칙
- GitHub Pages에서 바로 실행할 수 있도록 HTML, CSS, JavaScript 기반의 정적 구조를 유지합니다.
- 외부 빌드 도구 없이 수정·검증·배포가 가능하도록 관리합니다.
- 기존 기능은 유지하고 요청된 영역만 최소 범위로 변경합니다.

## 주요 파일
- `index.html`: 메인 애플리케이션
- `drawing_srcdoc_v82.html`: 손도면 관련 내장 화면
- `manifest.webmanifest`: PWA 설정
- `service-worker.js`: 오프라인 캐시
- `assets/`, `icons/`: 이미지와 앱 아이콘
