# 광전기통신 영업지원시스템

현재 버전: **v0.0.28**

## v0.0.28 변경사항

- PC 손도면 편집 화면의 단독 함체·적층 함체 3D 미리보기를 `선택 객체 설정` 오른쪽 패널로 이동했습니다.
- 기존 객체 편집 기능과 3D 탭 전환 기능은 그대로 유지했습니다.
- 모바일 및 중간 화면에서는 기존 반응형 규칙에 따라 3D 미리보기가 아래쪽으로 자동 재배치됩니다.
- 전체 면 PNG·PDF 및 공유 이미지의 마지막 빈 칸인 `하부면` 오른쪽에 현재 선택 함체의 `단독 함체` 입체도를 포함했습니다.
- 서비스 워커 캐시와 화면 버전을 v0.0.28로 갱신했습니다.

## v0.0.27 변경사항

- 손도면 생성의 제작 중요사항을 자유 입력 메모 1개 영역으로 단순화
- PC와 모바일에서 메모 입력 영역의 폭, 높이, 글자 크기 및 포커스 스타일 최적화
- 입력한 기타 중요사항을 전체 면 PNG·PDF·공유 이미지 하단에 그대로 출력
- 투명아크릴창을 정면에 부착된 투명 창처럼 보이도록 3D 표현 개선
- 투명아크릴창의 채움 투명도를 낮추고 얇은 테두리와 반사선만 표시하여 내부 부착물이 가려지지 않도록 수정
- 단독함체, 적층함체, 회전형 적층 3D에 동일한 투명 표현 적용
- 이외 기능과 데이터는 v0.0.26 상태 유지

## v0.0.26 변경사항
- 광 FDF 표를 품목 `FDF`와 규격 `4C`, `6C`, `4C 1U` 등으로 분리
- 자재 단가 계산기 적용 버튼을 함 파트와 동일한 디자인으로 통일
- 모바일 제품군 변경 및 검색 버튼 사용 시 검색창 자동 포커스 제거
- 손도면 객체 목록에 `투명아크릴창` 추가: 사각형 내부에 명칭 표시
- 명판 객체 선택 시 명판명 입력 가능, 도면·3D·공유 이미지에 해당 문구 반영
- 손도면 화면에 제작 중요사항 입력 패널 추가
- 도장색상, 문 방향, 아크릴창, 실크인쇄, 기타 메모를 PNG/PDF 공유 이미지 하단에 포함
- 서비스 워커 캐시 및 버전 갱신
