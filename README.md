# 광전기통신 영업지원시스템

## 현재 버전
v0.0.16

## 배포
이 폴더의 전체 파일을 GitHub 저장소 루트에 업로드하면 GitHub Pages에서 정적 웹앱으로 사용할 수 있습니다.


## v0.0.16 변경사항

- 자재파트의 세부 품목 선택 목록을 제거하고 제품군 중심 구조로 단순화
- 규격이 여러 개인 품목에 디자인된 `규격 보기` 버튼 적용
- 110블럭을 24P, 25P, 50P, 100P 규격으로 펼쳐서 확인하도록 구성
- 다중 규격 품목은 접힌 상태에서 단가를 표시하지 않도록 변경
- 기존 마우스 오버, 품목 선택, 제품 이미지 및 용도·참고사항 연동 유지
- 압축 해제 시 깨져 보이던 TXT 파일명을 제거하고 영문 파일명의 배포 안내문으로 정리

## v0.0.15 변경사항

- 자재파트 제품군 선택 목록에 `통합배선`, `광`, `TV`를 추가했습니다.
- 규격 및 단가 표의 품목 행을 클릭하면 한 품목만 선택되도록 구성했습니다.
- 기존 마우스 오버 효과를 유지하면서 선택된 행의 고정 강조 표시를 추가했습니다.
- 선택 품목에 연결되는 제품 이미지 영역과 용도 및 참고사항 영역의 기본 구조를 추가했습니다.
- 이미지, 용도, 참고사항이 미등록된 경우 안내 문구가 표시되도록 구성했습니다.

## v0.0.14 변경사항
- 기존 단가 글꼴·크기·정렬·원화 표시 방식은 유지하고, 조정률이 0%보다 클 때 단가 앞에 `▲10%`, `▲7.5%` 형태의 변동률 마크를 표시합니다.
- 조정률 0%에서는 변동률 마크를 표시하지 않습니다.
- 단가가 비어 있거나 미등록인 항목에는 변동률 마크를 표시하지 않고 기존처럼 `미등록`으로 표시합니다.
- 빠른 조정 버튼과 직접 입력 조정률 변경 시 전체 규격표의 변동률 마크와 조정 단가가 즉시 갱신됩니다.
- 공유 이미지의 대제목을 `제품정보`로 유지합니다.
- 브라우저 파비콘과 모바일 PWA 설치 아이콘에 회사 로고를 적용한 구성을 유지합니다.
- 서비스 워커 캐시 버전을 v0.0.14로 갱신했습니다.

## v0.0.12 변경사항
- v0.0.9를 기준으로 v0.0.10 가격조정 화면 유지 버그 수정을 통합했습니다.
- 단가 조정 버튼 사용 시 `함 제품` 또는 `함 관련 자재`의 현재 선택값이 유지되도록 수정했습니다.
- 함 관련 자재에 `단자대`를 추가하고 10P 10A, 10P 20A 단가를 등록했습니다.
- 함 관련 자재에 `국선보호기/피뢰탄기반`을 추가하고 5개 규격 단가를 등록했습니다.
- 함 관련 자재에 `접지 단자대`를 추가하고 70SQ~200SQ 규격 단가를 등록했습니다.
- 기존 `PVC속판/단프라`를 `속판/빼끄판/단프라/철망`으로 변경하고 9개 규격 데이터를 교체했습니다.
- 함 관련 자재에 `세대 덧박스`를 추가하고 가로·세로·깊이 8개 규격을 등록했습니다.
- 세대 덧박스의 연강 및 ABS 사출 단가는 미입력 상태이므로 화면에 `미등록`으로 표시됩니다.
- 서비스 워커 캐시 버전을 v0.0.12로 갱신했습니다.

## 이전 주요 변경사항
### v0.0.9
- 함 파트의 제품 선택 영역을 `함 제품`과 `함 관련 자재`로 분리했습니다.
- 두 선택창은 동시에 선택되지 않도록 연동했습니다.
- 모바일에서는 선택창이 세로로 정렬되도록 반응형 처리했습니다.

### v0.0.7
- 단가 조정 계산기에서 음수 조정 버튼을 제거했습니다.
- 직접 입력 조정률의 최솟값을 0%로 제한했습니다.

## 관리 원칙
- GitHub Pages에서 바로 실행할 수 있도록 HTML, CSS, JavaScript 기반의 정적 구조를 유지합니다.
- 외부 빌드 도구 없이 수정·검증·배포가 가능하도록 관리합니다.
- 기존 기능은 유지하고 요청된 영역만 최소 범위로 변경합니다.

## 주요 파일

- `service-worker.js`: 오프라인 캐시
