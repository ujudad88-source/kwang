# 광전기통신 영업지원시스템

## 버전
v0.0.26

## v0.0.26 변경사항
- 광 FDF 표를 품목 `FDF`와 규격 `4C`, `6C`, `4C 1U` 등으로 분리
- 자재 단가 계산기 적용 버튼을 함 파트와 동일한 디자인으로 통일
- 모바일 제품군 변경 및 검색 버튼 사용 시 검색창 자동 포커스 제거
- 손도면 객체 목록에 `투명아크릴창` 추가: 사각형 내부에 명칭 표시
- 명판 객체 선택 시 명판명 입력 가능, 도면·3D·공유 이미지에 해당 문구 반영
- 손도면 화면에 제작 중요사항 입력 패널 추가
- 도장색상, 문 방향, 아크릴창, 실크인쇄, 기타 메모를 PNG/PDF 공유 이미지 하단에 포함
- 서비스 워커 캐시 및 버전 갱신
