KENC UI 2.0 / 3.0.0 - Professional CAD & Realistic Cabinet Foundation

적용 순서
1. CAD 상태 엔진: Grid, Ortho, Polar, Snap, 명령행
2. 선택/변형: 정밀 이동, 복사, 회전, 대칭, 삭제, 잠금
3. 레이어: CABINET, COVER, OBJECT, CUT, DIM, CENTER, HIDDEN
4. 배열: 행/열 및 간격 기반 사각 배열
5. 실물 재질: 분체도장, 아연도금, 스테인리스, 블랙 도장, RAL/광택/주변광
6. 제작 교환: ASCII DXF, BOM CSV, 카바 전개도, 충돌 검사
7. 명령: MOVE, COPY, ROTATE, MIRROR, ARRAY, LAYER, ERASE, DXF, ZE
8. 기존 실사형 객체 렌더러 및 통합 Scene Graph 유지

중요
- 이번 버전은 함체 설계에 필요한 전문 CAD 기반을 통합한 버전입니다.
- AutoCAD 전체 기능이나 제조사별 CNC 절곡 보정까지 완전히 동일한 상용 CAD 대체를 의미하지 않습니다.
- DXF는 2D LINE 기반 교환용이며, CNC 투입 전 제작 설비 기준 검토가 필요합니다.
